# hoyolab_auto

Automated HoYoLAB Daily Check-in, ZZZ Howl Scratch Card, Auto Code Redeem, and Mimo points runner powered by GitHub Actions.

## Setup Instructions

1. Go to **Settings** -> **Secrets and variables** -> **Actions** in this repository.
2. Add a new repository secret named `HOYOLAB_COOKIE`.
3. Paste your HoYoLAB Cookie string.
4. (Optional) Add `DISCORD_WEBHOOK` secret for Discord notifications.
5. The action will run automatically every day at 00:00 WIB!
